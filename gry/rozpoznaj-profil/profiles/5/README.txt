PROFIL 5 Z 8 — KATARZYNA GRADOWSKA

Polska adaptacja ćwiczenia o fałszywej ekspertce od kryptowalut i sieci fikcyjnych kont publikujących referencje.

Uruchomienie:
1. Rozpakuj paczkę.
2. Otwórz index.html albo wgraj całą zawartość katalogu do repozytorium GitHub Pages.
3. Nie zmieniaj struktury katalogu assets.

Zawartość:
- index.html
- style.css
- app.js
- .nojekyll
- assets/ — lokalne grafiki, strona nie wymaga zewnętrznych bibliotek

Wszystkie polskie nazwiska, kwoty, platforma Portfel+ i przedstawione transakcje są fikcyjne. Materiał służy wyłącznie edukacji medialnej i profilaktyce oszustw.


WERSJA FOTOGRAFICZNA:
Posty referencyjne korzystają z fotografii już obecnych w paczce zamiast z prostych plansz ilustracyjnych. Nie generowano nowych zdjęć.
