# Lokalny CMS

Ten katalog zawiera panel zarządzania statyczną stroną projektu. Szczegółowa instrukcja znajduje się w pliku `CMS-INSTRUKCJA.md` w katalogu głównym paczki.

Panel jest częścią projektu, dlatego po każdym eksporcie pozostaje dostępny także w nowej wersji ZIP. Edytor stron obsługuje treść, wyrównanie, szerokość, krój i rozmiar pisma, kolory oraz odstępy bloków tekstowych.
