# Edukacja bez granic — Portal V69.6 z rozbudowanym CMS

Kompletny, statyczny portal przygotowany do publikacji przez GitHub Pages.

## Publikacja na GitHub

1. Utwórz nowe repozytorium.
2. Wgraj **zawartość tego katalogu** do głównego katalogu repozytorium.
3. W ustawieniach repozytorium przejdź do **Pages**.
4. Wybierz publikację z gałęzi `main` i katalogu `/ (root)`.
5. Zapisz ustawienia i poczekaj na wygenerowanie adresu strony.

Plik `.nojekyll` jest już dołączony. Portal nie wymaga kompilacji, serwera ani instalowania zależności.

## Najważniejsze pliki

- `index.html` — strona główna.
- `nasze-szkolenia.html`, `zapisy.html`, `kursy-online.html`, `kontakt.html` — dopracowane podstrony publiczne.
- `assets/portal-v67.css` — bazowy system wizualny.
- `assets/portal-v68.css` — większa typografia, zwarty rytm i docelowe układy podstron.
- `DESIGN-SYSTEM-V68.md` — parametry siatki, typografii, zdjęć i logotypów.
- `grafiki/` — istniejące fotografie i oficjalne logotypy.

## Treść

Widoczne teksty stron publicznych zostały zachowane zgodnie z wersją źródłową V63.
Jedyną świadomą zmianą redakcyjną jest skrócenie etykiety „Dla kogo pracujemy” do „Dla kogo”.

## Zasada dotycząca logotypów

W nagłówku i stopce wykorzystywane są istniejące pliki projektu. Nie należy ich deformować, przycinać ani zastępować tekstem.
